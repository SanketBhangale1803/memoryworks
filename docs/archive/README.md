# Archive

when it was built around extracted runbooks, simulation, drift checks, and a
separate agent-operations console. Those surfaces are gone: MemoryWorks is now
the company brain, used from one chat window with Ask and Agent modes.

These documents are kept as a record of what was planned and why. They do not
describe the current product; start from the [README](../../README.md) and
[`ARCHITECTURE.md`](../ARCHITECTURE.md) instead.
